# Pengingat Servis Matik

Kalkulator sederhana untuk menghitung sisa kilometer sebelum **ganti oli** dan **servis CVT + injeksi** motor matic.

**Cara pakai**
1. Isi angka odometer sekarang.
2. Isi KM terakhir ganti oli dan terakhir servis CVT.
3. Atur jarak servis sesuai buku servis motormu (bawaan: oli tiap 2.000 km, CVT tiap 4.000 km).

Rumus: `(KM terakhir servis + jarak interval) − KM sekarang`

Data tersimpan di browser masing-masing pengguna, tidak dikirim ke mana pun.
